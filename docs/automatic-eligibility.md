# 自動掲載の運用

短い感想、ライブや番組の感想、個人的な観察や批判、複数グループの比較などを通常掲載の対象にします。文章の長さ・完成度・人気は判定に使いません。

## 判定と再取得

- 見出しの坂道グループ、人物、番組、作品と、感想・その人の活動などの組み合わせを使います。見出しが抽象的なときは、公開フィードの配信本文・冒頭文・タグから具体的な主題を確認します。本文だけが手掛かりの場合は、序盤の活動描写や複数の文での関連を確認し、ランキング表示や脇の言及は根拠から外します。一般語と同じ作品名や愛称には別の手掛かりを求めます。
- 専門の書き手は、直近30記事のうち10件以上の観測があり、8割以上が確かな坂道の対象を伴う掲載記事である場合に認識します。過去の掲載・確認記録と坂道固有の用語を組み合わせて判定を補助します。混在する書き手や履歴の少ない書き手は、記事ごとの手掛かりを主に使います。登録中の書き手の新着は個別承認なしで処理します。
- 収集経路は登録済みの公開フィードと確認済みのマガジンです。フィードの著者境界を確認し、停止中・未確認のフィードや第三者のURLを混入させません。未登録の媒体に対する自動発掘はこの更新の対象外です。
- 配信本文やタグがない場合は、日時が確認できる見出しと既存の確認記録を利用します。RSSウィンドウの外に出た記事は、保存済みメタデータを再評価します。フィードで公開されている本文を処理後に破棄します。個別記事ページの定期巡回、認証付き本文・有料本文の取得、非公開API、AI APIは使いません。
- 一時的な通信障害は同じ取得で最大1回再試行します。取得制限が示された場合は後続の定期実行に委ねます。公開日時を確認し、重複URLは正規化して同一記事にまとめます。

## 状態と運営者の操作

| 状態 | 意味 |
| --- | --- |
| `published` | 掲載。公開サイトで元記事の公開日を使います。 |
| `excluded` | 明確な対象外、創作、広告・告知のみ、または明示された非掲載。 |
| `retry` | 情報待ち。定期実行で再評価し、最初の検知から72時間で終了します。 |
| `unresolved` | 期限までに情報が揃わなかった記事。理由と公開日を保管し、RSSで情報が戻った場合は再判定します。 |
| `pending` | 管理者が明示した停止・確認、またはプライバシー等の記録がある例外。 |

従来の本文確認待ちは再評価します。旧判断の証拠は `config/overrides.json` に保持し、除外、掲載停止、明示的な手動保留を優先します。掲載停止には既存の管理機能の `remove_article` または `remove_source`、例外の調査中は `hold_article` を使います。通常の記事確認のために管理機能を使う必要はありません。

公演名や愛称などの補足語彙は、公式の番組・公演・作品一覧を照合して `config/rules.json` のグループ別辞書に追加できます。一般語や複数の対象に当てはまる語は、組み合わせで判定する語彙に追加してください。

## 障害時の確認

Actions の収集ジョブ要約に取得・判定の件数を出します。`state/eligibility.json` には、状態遷移、理由別件数、書き手別の方式・再判定率、期限に達した記事の状況を記録します。初回検知から掲載判定までの時間には、既存保留の待ち時間も含みます。公開までの時間は、収集開始時刻と Actions の公開照合ステップの完了時刻から確認できます。公開工程が失敗した場合も、それまでに保存した判定済み記事は次の更新に引き継ぎます。

## ブログ・マガジンのRSSが取得できなくなった場合

- RSSがHTTP 404を返した場合は、通常の収集で再確認します。24時間以上にわたる連続3回以上の404、またはHTTP 410で、そのRSSだけを休止します。
- 休止中のRSSは7日経過後の定期更新で再確認します。取得・解析に成功すれば自動復帰します。設定のRSS URLを変更した場合は次回収集で新URLを確認します。選択収集（`--source-id`）では休止期間中も確認できます。
- 取得制限・サーバー障害・空または不正形式のRSSは取得エラーとして記録し、次回の収集で再確認します。Pagesに公開する更新は、収集を実行した際に1件以上のRSSを確認できた場合に進みます。
- RSSの応答を理由に、既存の記事情報、書き手、承認・除外履歴を消しません。リンク先の記事が削除されている場合、元サイトでは閲覧できません。掲載取り下げには既存の管理操作が適用されます。
- Actionsの実行サマリーと公開サイトのRSS取得状況で、対象、HTTPステータス、次回確認予定を確認できます。
